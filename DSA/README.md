# DSA Learning Curriculum

This curriculum is designed to help you build a strong foundation in Data Structures and Algorithms (DSA) from beginner to interview-ready level.

## 1. Goals

By the end of this roadmap, you should be able to:

- Understand the core data structures and when to use them
- Analyze time and space complexity confidently
- Solve coding problems using patterns, not memorization
- Prepare for technical interviews and coding assessments
- Write clean, efficient, and testable solutions

## 2. How to Learn DSA Effectively

Follow this approach for every topic:

1. Learn the concept and intuition
2. Study the complexity analysis
3. Solve 3–5 easy problems
4. Solve 2–3 medium problems
5. Review and optimize the solution
6. Repeat the pattern on a different problem

Important: do not jump to advanced topics before mastering the basics. DSA is cumulative.

## 3. Recommended Study Schedule

A practical weekly structure:

- 5 days/week: 1–2 hours of problem solving
- 1 day/week: review and revision
- 1 day/week: mock interview or timed contest practice

Suggested daily rhythm:

- 15 min: revise concept
- 30–45 min: solve problems
- 20–30 min: analyze mistakes and improve

## 4. Roadmap

### Phase 1: Foundations

Focus: programming fundamentals and problem-solving mindset

Topics:
- Variables, loops, conditions, functions
- Complexity analysis: O(1), O(log n), O(n), O(n log n), O(n^2)
- Recursion and backtracking basics
- Arrays and strings fundamentals
- Debugging and tracing code

Practice goal:
- Solve 20–30 easy problems
- Be comfortable with writing clean code from scratch

Recommended problems:
- Find max/min in array
- Reverse a string
- Check palindrome
- Missing number
- Two-sum basics

### Phase 2: Core Data Structures

#### Arrays and Strings
- Static vs dynamic arrays
- Indexing and traversal
- Prefix sums
- Sliding window
- Two pointers
- String manipulation patterns

Key concepts:
- Subarray and substring problems
- Window optimization
- Sorting and searching fundamentals

Practice goal:
- 15–20 array problems
- 10–15 string problems

#### Linked Lists
- Singly linked list
- Doubly linked list
- Circular linked list
- Insert/delete/traverse operations
- Fast and slow pointers

Practice goal:
- 8–12 linked list problems

#### Stacks and Queues
- LIFO/FIFO principles
- Monotonic stacks
- Next greater element
- Valid parentheses
- Queue operations and usage in BFS

Practice goal:
- 8–10 problems each

#### Hashing
- Hash maps and hash sets
- Frequency counting
- Grouping and lookup problems
- Collision handling basics

Practice goal:
- 10–15 medium problems

### Phase 3: Intermediate Algorithms

#### Trees
- Binary tree basics
- Tree traversals: preorder, inorder, postorder
- Level-order traversal
- Binary search tree (BST)
- Height, depth, diameter
- Lowest common ancestor

Practice goal:
- 15–20 tree problems

#### Binary Search
- Search in sorted arrays
- Lower bound / upper bound
- Search in rotated arrays
- Binary search on answer

Practice goal:
- 10–15 problems

#### Sorting and Searching
- Merge sort
- Quick sort
- Heap sort
- Counting sort (where relevant)
- Binary search variations

Practice goal:
- Understand the idea, not just implementation

#### Greedy Algorithms
- Local optimization vs global optimization
- Activity selection
- Fractional knapsack
- Job scheduling
- Interval problems

Practice goal:
- 5–8 greedy problems

### Phase 4: Advanced Problem Solving

#### Graphs
- Graph representations: adjacency matrix/list
- DFS/BFS
- Topological sort
- Connected components
- Shortest path: BFS, Dijkstra
- Cycle detection
- Union-find / Disjoint set

Practice goal:
- 15–20 graph problems

#### Dynamic Programming
- Overlapping subproblems
- Optimal substructure
- 1D DP, 2D DP, memoization, tabulation
- Knapsack patterns
- Longest subsequence and substring problems
- House robber, climbing stairs, coin change, edit distance

Practice goal:
- Solve at least 15 DP problems across easy/medium difficulty

#### Backtracking
- N-Queens
- Permutations and combinations
- Subset generation
- Sudoku-like problems
- Decision tree search

Practice goal:
- 5–10 backtracking problems

#### Heaps and Priority Queues
- Min-heap / max-heap
- Top K problems
- Merge K sorted lists
- Heapify fundamentals

Practice goal:
- 8–10 problems

### Phase 5: Competition and Interview Preparation

Topics:
- Bit manipulation
- Trie
- Segment trees
- Fenwick trees
- Advanced graph algorithms
- Practice with real interview-style questions

Goal:
- Build speed and confidence
- Solve medium problems in under 30–40 minutes
- Handle edge cases consistently

## 5. Suggested Problem Progression

Use this order while solving problems:

- Easy: Learn the pattern
- Medium: Improve speed and creativity
- Hard: Understand the approach, but don’t get stuck for too long

A good rule:

- If stuck for more than 25–30 minutes on a problem, read the editorial or hint
- After understanding the solution, re-solve it without looking

## 6. Weekly Learning Template

Week 1–2:
- Arrays, strings, complexity

Week 3–4:
- Linked lists, stacks, queues, hashing

Week 5–6:
- Trees, BST, recursion, binary search

Week 7–8:
- Graphs, BFS/DFS, heaps, greedy

Week 9–10:
- Dynamic programming

Week 11–12:
- Backtracking, advanced patterns, mock interviews

## 7. Practice Platforms

Choose one primary platform and one backup:

- LeetCode
- NeetCode
- HackerRank
- GeeksforGeeks
- Codeforces (for advanced practice)

Recommended practice mix:

- 60% concept-based problems
- 30% medium-level interview problems
- 10% hard problems for stretch

## 8. Interview Preparation Checklist

Before an interview, you should be comfortable with:

- Explaining your approach clearly
- Writing code without syntax errors
- Tracking edge cases
- Analyzing complexity
- Choosing the right data structure
- Optimizing suboptimal solutions

## 9. Common Mistakes to Avoid

- Memorizing code without understanding the idea
- Ignoring complexity analysis
- Skipping easy problems because they feel too basic
- Moving to the next topic without revising previous ones
- Solving only one pattern without practicing variations

## 10. Final Advice

DSA is a skill that improves through consistent repetition. You do not need to solve hundreds of problems every week. You need to solve the right problems deeply and review them regularly.

The best approach is:

- Learn one concept
- Solve a handful of related problems
- Review mistakes
- Repeat

If you practice consistently, you will build strong intuition and become comfortable with algorithmic thinking.

## 11. Suggested Milestones

- Beginner: solve 50–100 easy problems
- Intermediate: solve 100–200 mixed problems
- Advanced: solve 300+ problems with strong review habits
- Interview-ready: can explain and code solutions for core topics without notes

## 12. Recommended Order of Topics

1. Arrays and strings
2. Complexity analysis
3. Hashing
4. Linked lists
5. Stacks and queues
6. Recursion
7. Trees
8. Binary search
9. Graphs
10. Heaps
11. Greedy
12. Dynamic programming
13. Backtracking
14. Advanced data structures and contests

## 13. One-Year Learning Plan

If you want a longer plan, divide the year into 4 quarters:

- Quarter 1: Foundations and arrays/strings
- Quarter 2: Linked lists, trees, hashing, stacks/queues
- Quarter 3: Graphs, heaps, greedy, binary search
- Quarter 4: DP, backtracking, mock interviews, revision

This gives enough time to build depth instead of rushing through topics.

## 14. Conclusion

DSA is not about memorizing algorithms alone. It is about pattern recognition, choosing the right tool, and solving problems efficiently under constraints.

Keep learning, keep practicing, and keep reviewing. That is the real path to mastery.
