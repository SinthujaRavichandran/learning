# DSA Weekly Learning Plan

This weekly plan is built from the main DSA curriculum and organized into Basic, Intermediate, and Advanced topics. It is designed for steady progress over 12 weeks, with daily practice and revision built in.

## 1. Learning Structure

| Level | Focus | Description |
|---|---|---|
| Basic | Foundations | Core problem-solving skills and programming fundamentals |
| Intermediate | Data structures and patterns | Standard structures and common algorithmic techniques |
| Advanced | Optimization and interview depth | Graphs, DP, backtracking, and higher-order problem solving |

| Weekly rhythm | Details |
|---|---|
| Learning days | 5 days/week |
| Revision day | 1 day/week |
| Mock practice day | 1 day/week |

## 2. Weekly Breakdown by Level

### Basic Topics

These topics build the foundation for all later DSA learning.

| Week | Topic | Key Concepts | Practice Goal |
|---|---|---|---|
| Week 1 | Programming Fundamentals and Complexity | Variables, loops, conditions, functions; input/output; debugging; time and space complexity | 8–10 easy problems |
| Week 2 | Arrays and Strings Fundamentals | Array indexing; string operations; reverse/palindrome/anagram basics; two pointers; sliding window | 10–12 easy/medium problems |
| Week 3 | Hashing and Recursion Basics | Hash maps and sets; frequency counting; recursion; base case; recursion stack | 8–10 problems |

### Intermediate Topics

These are the standard structures and algorithmic patterns used in technical interviews.

| Week | Topic | Key Concepts | Practice Goal |
|---|---|---|---|
| Week 4 | Linked Lists | Singly/doubly linked list; insert/delete/traverse; reverse list; slow and fast pointers | 8–10 problems |
| Week 5 | Stacks and Queues | LIFO/FIFO logic; parentheses validation; monotonic stack; next greater element | 8–10 problems |
| Week 6 | Trees and Binary Search Trees | Tree terminology; traversals; level-order; BST insert/search; height and depth | 10–12 problems |
| Week 7 | Binary Search and Sorting | Binary search patterns; lower/upper bound; rotated arrays; merge sort; quick sort | 10 problems |
| Week 8 | Greedy and Heaps | Greedy patterns; activity selection; interval scheduling; min-heap/max-heap; top K | 8–10 problems |

### Advanced Topics

These topics require stronger pattern recognition and deeper reasoning.

| Week | Topic | Key Concepts | Practice Goal |
|---|---|---|---|
| Week 9 | Graphs I | Graph representations; DFS/BFS; connected components; cycle detection; shortest path | 8–10 problems |
| Week 10 | Graphs II and Dynamic Programming I | Topological sort; Dijkstra basics; DP fundamentals; memoization vs tabulation; Fibonacci, climbing stairs, house robber | 8–12 problems |
| Week 11 | Dynamic Programming II and Backtracking | Knapsack patterns; longest subsequence; subset/permutation generation; N-Queens; Sudoku-style backtracking | 8–10 problems |
| Week 12 | Advanced Review and Mock Interview Preparation | Revision; re-solving missed questions; timed sessions; mock interviews; complexity optimization | 2–3 mixed coding rounds |

## 3. Suggested Daily Routine

| Day | Focus |
|---|---|
| Monday | Learn concept, read examples, solve 2 easy problems |
| Tuesday | Solve 2 medium problems and review time complexity |
| Wednesday | Learn one pattern variation and solve 2 practice problems |
| Thursday | Mini revision from previous topics and solve 1 challenge problem |
| Friday | Mixed-question day with focus on speed and correctness |
| Saturday | Revision and error analysis; re-solve 2 wrong questions |
| Sunday | Mock test or timed practice; revisit weak topics |

## 4. Problem Goals by Week

| Hard problems | 1–2 (only after understanding the pattern) |

## 7. Success Rule

Do not move to the next topic without completing at least:

| Requirement | Minimum |
|---|---|
| Easy problems | 2–3 |
| Medium problems | 2 |
| Error review session | 1 |

This keeps learning consistent and prevents gaps in understanding.

## 8. Final Target

By the end of 12 weeks, you should be able to:

| Goal |
|---|
| Solve beginner-to-intermediate problems confidently |
| Explain the logic behind core algorithms |
| Choose the right data structure for a problem |
| Handle tree, graph, and DP patterns with confidence |
| Appear ready for coding interviews and technical assessments |
